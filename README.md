### Personal Reflection

During this Web Refresher activity, I worked on a responsive student portfolio using HTML5, CSS and JavaScript. I found organising the webpage with semantic HTML elements relatively straightforward because each section had a clear purpose. I also practised using CSS Grid and Flexbox to organise the content.

The most challenging part was making the layout work well on smaller screens and understanding how JavaScript changes webpage elements. I used browser developer tools to examine different screen sizes and check for errors. This helped me understand how media queries and DOM event handling work together to create a better user experience.

During Web Development II, I would like to improve my JavaScript skills, particularly DOM manipulation, event handling and building more complex interactive features. These skills will help me develop more responsive and accessible websites.
